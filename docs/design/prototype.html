Drillbit, as shipped

A faithful HTML recreation of the current iOS app (4 Oct 2026), screen by screen, so changes can be made here first. Copy, states and fixture content match the simulator captures in the teardown. Each phone is clickable; captions name the Swift view. Default appearance is dark because the app's stored default is dark; flip to light to see the other mode.

Decisions

  • 4 Oct: the user chose to start from a faithful recreation of the shipped app and change it incrementally, instead of a redesign from scratch. The earlier redesign draft is kept at draft-r1.html for parts worth lifting (lane canvas, step bar).
  • 4 Oct: agreed direction for the changes to come: lanes + slots canvas; Libron for reading text; tiny steps inside the interview; a fixed five-step path for every mode; voice shows the canvas read-only until a finalized-turn boundary exists; Bit on Welcome and feedback only; Recall + Library fold into one Map tab; the gate stays after the first feedback and gains a CTA.

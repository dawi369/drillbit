Drillbit, redrawn

One page, clickable phones. Every screen names the Swift view it replaces and is tagged by what it needs: view SwiftUI only · content authoring · API contract change (OpenAPI + fixtures + DTOs) · model prompt or schema change. Flows ride the real turn model: a draft autosaves, Send is a durable answer, the interviewer replies with a follow_up; a single line ending in “?” is a clarification. Grounding: teardown, steal list, cheap cut.

What changed from the app

  • No eyebrow caps. Hierarchy comes from Libron sizes and spacing.
  • No cards. Only the canvas and the composer are inset surfaces.
  • One accent, used for the current step, the request dot and “what to fix”. Primary buttons are ink.
  • Bit twice: when the Welcome fix lands, and on feedback.

Turn model

  • Requirements lines → one answer with the lines joined.
  • A move is a local check; the pick is then sent as an answer so the interviewer reacts to it. Needs moves[] on the generated question and step in every reply.
  • The canvas serialises to {nodes, edges} and rides the same answer command (additive field).

Open questions this round

  • Setup: is one screen too dense at larger text sizes? (Chips wrap.)
  • Design step: do you want the sentence field at all, or diagram-only?
  • Feedback: five-step review replaces the Mock Strong/Mixed/Weak card. Is “thin / missed” honest enough?
  • Title face: Libron Bold is used for titles too. A second display face is possible; say if you want to see one.

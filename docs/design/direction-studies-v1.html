Proposed first-session journey

Show the value. Ask only what helps.

A single promise replaces the four-page introduction. Two relevant choices shape the first session. A local input preview sets expectations before authentication. Invitations remain a separate access gate.

Evidence is the signature

Quote → observation → next action. Repeat the same visual grammar in onboarding, feedback, and Recall. Avoid invented scores or mastery claims.

Every state has a next action

Keep drafts during interruption. Explain pending feedback. Show recoverable errors in place. Design these states before broad implementation.

Material follows hierarchy

Use blur at navigation boundaries. Keep reading and editing surfaces legible. An opaque fallback must preserve hierarchy and contrast.
